# Archive — Version 1 (projet d'origine)

Ce dossier conserve la **toute première version** du projet, telle qu'elle existait au départ.
Elle est gardée pour l'historique. **Le projet actuel se trouve à la racine du dépôt** (voir le README principal).

Ce qu'il y a ici :

- **`plateforme-v1/`** — la première plateforme d'analyse. Elle reposait sur une IA et était lente (environ **2 min 42** par analyse). La version actuelle fait la même chose en **~15 secondes**, avec de vrais outils (Nmap, Nikto, SSLScan, ZAP).
- **`site-denim/`** — le premier site cible, une boutique de démonstration (« DenimLab »). Il a été remplacé par **NetStock Lab**, une boutique que j'ai codée moi-même, en version vulnérable et en version corrigée.
- **`recherche/`** — les documents de recherche et le rapport initial du projet.

Démonstration vidéo de cette première version : https://youtu.be/Qu1QHISt_pI

> Cette archive montre le point de départ. L'intérêt du projet est justement le **chemin parcouru** depuis.
